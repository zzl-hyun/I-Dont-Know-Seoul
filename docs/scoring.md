# 등급은 어떻게 나오는가

← [README](../README.md)

등급은 **절대 평가가 아니라 서울 안에서의 상대 평가**입니다. 상위 30%가 Best,
하위 30%가 Bad입니다. "Bad"는 살 수 없는 동네라는 뜻이 아니라, 같은 조건에서
비교했을 때 서울 하위권이라는 뜻입니다.

---

## 한 동네를 끝까지 따라가 보기

관악구 신림동을 예로 다섯 단계를 전부 관통해 보겠습니다.

### 1단계 — 원지표 수집

```
유흥업소 185.29개/km²   월세 57.92만원   편의점·마트 110.39개/km²
역까지 도보 6.43분      버스 정류장 31.54개/km²
```

### 2단계 — 대상 547개 동 안에서 백분위로 환산

```
유흥업소 185.29개/km² → 백분위 0.0
```

유흥업소는 많을수록 치안에 불리한 지표라 백분위를 뒤집습니다. 신림동은 대상
지역에서 밀도가 가장 높아 0점입니다. 반대로 0개인 동도 547개 중 178개라, 동점
평균 순위를 적용하면 100점이 아니라 **83.7점**입니다. 화면에서도 원지표와 백분위를 함께
보여줘 이 방향과 동점 처리를 확인할 수 있게 합니다.

백분위를 쓰는 이유는 두 가지입니다. 강남 월세 같은 이상치 하나에 전체 분포가
끌려가지 않고, 단위가 다른 지표(개/km², 만원, 분)를 같은 축에서 섞을 수 있습니다.
평균/표준편차나 min-max 정규화로는 둘 다 안 됩니다.

### 3단계 — 축 점수 (하위 지표의 가중합)

```
생활편의 95.7 = 97.6×0.30 + 98.0×0.25 + 97.4×0.20 + 90.1×0.175 + 89.3×0.075
                편의점       음식점       병원         역도보       버스
```

교통(역 도보 + 버스)의 합은 0.25이고 그 안에서 **지하철 7 : 버스 3** 입니다.
서울에서 지하철이 정시성·속도 모두 우위인 데다, 무엇보다 이 앱의 통근시간 계산
자체가 지하철만 씁니다. 버스 정류장 밀도는 독립적인 교통 지표라기보다 "지하철이
안 닿는 동네의 보완재" 입니다.

### 4단계 — 종합 점수 (사용자 가중치)

```
54.5 = 12.1×0.40 + 73.6×0.35 + 95.7×0.25
       치안         가격         편의
```

치안 12.1은 유흥업소 백분위 0.0, 5대범죄 20.9, 교통사고 다발지역 15.8의
가중합입니다. 내부 가중치는 각각 0.385 / 0.462 / 0.154입니다.

치안은 낮지만 가격과 생활편의가 높아 기본 가중치에서 547개 동 중 **213위**로
중간권입니다. 한 축만 보고 동네 전체를 단정하지 않는다는 예시입니다.

### 5단계 — 등급 컷

서울 전체 분포에서 상위 30% 지점의 점수 이상이면 Best입니다. 가중치를 바꾸면
점수 분포가 통째로 이동하므로 **이 컷도 함께 움직입니다.**

절대 컷(예: 70점 이상 Best)을 쓰면 가중치를 바꾸는 순간 대부분이 한 등급으로
몰려 지도가 무의미해집니다.

## 왜 슬라이더가 있는가

**정답이 사람마다 다르기 때문입니다.** 월세가 제일 중요한 사람과 조용한 동네가
제일 중요한 사람에게 같은 순위를 강요할 근거가 없습니다.

축 점수를 백분위로 저장해두면 종합 점수는 클라이언트에서 **547회 곱셈**이면
되므로, 슬라이더를 사실상 공짜로 제공할 수 있습니다. 움직이면 등급·추천 순서·
요약 문장이 전부 즉시 바뀝니다.

| 축 | 무엇을 보는가 | 기본 |
|---|---|---|
| **치안** | 유흥업소 밀도, 5대범죄(자치구), 교통사고 다발지역 | 40% |
| **가격** | 환산월세 중앙값 (단독·다가구·오피스텔·소형아파트) | 35% |
| **생활편의** | 편의점·마트, 음식점, 병원·약국 밀도, 교통 접근성(역 도보 + 버스) | 25% |

각 지표를 어디서 가져오는지와 왜 그 출처를 골랐는지는 [데이터](./data.md) 참고.

## 요약 문장은 가중치를 반영합니다

극단값 순으로만 지표를 고르면 신림동 요약이 *"병원·약국이 가깝고 역이 가깝고
편의점·마트가 많습니다"* 가 됩니다 — 자취방을 찾는데 월세가 빠집니다.

그래서 극단성에 **그 지표가 최종 점수에 기여하는 비중**을 곱해 우선순위를
정합니다. 슬라이더를 움직이면 문장도 따라 바뀌는데, 그게 맞는 동작입니다.

좋은 점만 나열하면 광고가 되고 나쁜 점만 나열하면 낙인이 되므로, 양쪽이 다
있으면 역접으로 섞습니다. Bad 등급이면 부정 요인을 앞에 둡니다.

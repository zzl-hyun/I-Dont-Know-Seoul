01

안녕하세요. 서울을 전혀 모르는 사람을 위한 자취 지역 탐색 서비스, I Don't Know Seoul을 소개하겠습니다.

🌙 어느 자취생의 이야기

옛날 옛날, 전주에 살던
한 청년이 있었습니다

첫 직장이 판교로 정해진 날, 청년은 신이 났더랍니다. 그런데 기쁨도 잠시, 막막해졌어요.
서울 근처에 아는 동네라고는 텔레비전에서 들어본 강남, 신림, 노량진뿐이었거든요.
회사 근처가 조용한 동네인지, 밤길이 무섭진 않은지, 월세는 얼마쯤인지 — 물어볼 사람이 없었습니다.
결국 부동산 앱에서 눈에 띄는 매물부터 골랐고, 그 동네가 어떤 곳인지는 이사하고 나서야 알게 되었답니다.

압니다

이 청년, 사실 저입니다.

02

사실 이거 제 얘기예요. 판교로 취업하면서, 서울 지리를 하나도 모른 채로 자취방을 구해야 했거든요. 여기서부터는 진지하게 가보겠습니다.

낯선 동네가 만드는 문제

아는 사람이 없으면,
비교할 기준도 없습니다

좁은 후보

신림·노량진처럼 이름을 들어본 동네만 후보에 오릅니다. 조건이 더 좋은 동네가 있어도 모릅니다.

뒤바뀐 순서

동네를 먼저 고르는 게 아니라, 매물을 먼저 찾고 그 동네를 받아들이게 됩니다.

비교 불가능한 후기

커뮤니티 후기는 있어도 개인 경험이라, 이 동네가 몇 등인지는 아무도 알려주지 않습니다.

뒤늦은 확인

통근 1시간 20분, 편의점까지 도보 12분 — 이사하고 나서야 알게 됩니다.

부동산 앱은 매물 중심이라 동네 탐색을 건너뜁니다
지도 앱은 출발지가 있어야만 작동합니다
커뮤니티는 표본이 한쪽으로 치우쳐 있습니다
03

이 청년이 겪은 문제를 정리하면 네 가지입니다. 기존 부동산 앱도, 지도 앱도, 커뮤니티도 이 문제를 온전히 풀어주지 못했습니다.

그래서 이렇게 풀었습니다

목적지만 찍으면, 후보 지역 전체를
같은 잣대로 비교합니다

아는 동네가 없어도 후보가 생깁니다

547개 행정동을 공공데이터로 자동 채점합니다. 치안 30% · 가격 35% · 편의 35%.

근거를 끝까지 확인할 수 있습니다

원지표 → 백분위 → 가중치 → 종합점수까지, 계산 과정을 전부 펼쳐 보여줍니다.

실거주 후기가 지인의 조언을 대신합니다

나와 비슷한 통근 조건을 가진 사람의 후기부터 우선 보여줍니다.

대부분 로그인 없이 씁니다

탐색·조회는 전부 무료. 로그인은 내가 후기를 남길 때만 필요합니다.

04

왼쪽이 이번 설계의 차별점, 등급 계산 근거 공개입니다. 오른쪽은 로그인부터 후기 작성까지 이어지는 흐름이고요.

데이터 모델 · KV + D1 하이브리드

읽기 전용은 KV, 사용자가 만드는 데이터는 D1

547개 행정동의 지표·경계·점수는 배치가 통째로 교체하는 읽기 전용 번들이라 KV에 둡니다. 계정·후기처럼 제약조건과 조인이 필요한 데이터만 관계형 D1에 둡니다.

08

조회 패턴이 다른 데이터를 저장소도 다르게 뒀습니다. 지표는 통째로 읽는 KV, 후기는 조인과 제약조건이 필요한 D1입니다.

09

쓰기 API는 후기와 인증뿐입니다. 나머지는 전부 조회고, 실제 계산은 브라우저가 합니다 — API 개수를 줄인 게 아니라, 애초에 서버가 할 일이 적은 구조입니다.

고민한 점 · 다음 단계

이번엔 일부러 단순하게 뒀습니다

◐ 의도적으로 축소한 것

  • 통근 페널티 Φ(t)실제 서비스는 통근이 길수록 점수를 서서히 깎지만, 이번 설계는 "상한 넘으면 제외"라는 단순 필터로 정의했습니다.
  • 행정동 547 vs 556이번 설계 범위(신분당선 축)와 실제 서비스(GTX-A 동탄 포함)의 차이입니다. 만든 사람이니까 아는 차이입니다.
  • 후기 신고·제재운영 주체가 없는 설계라 이번엔 넣지 않았습니다.

◑ 다음 스프린트에 붙일 것

  • 인증·후기 서버 구현SCR-AUTH-001 / RVW-001 / RVW-002는 설계가 끝났고, D1 스키마도 준비됐습니다. 다음은 실제 엔드포인트입니다.
  • 지표 스냅샷 버전 관리지금은 최신 값 한 벌만 KV에 올립니다. 배포 이력 추적과 롤백을 다음 단계로 미뤘습니다.
  • 주택유형별 월세 세분화단독·다가구부터 아파트까지 나눠 보여주는 건 실제 서비스 기능이고, 이번 설계는 단일 지표로 단순화했습니다.

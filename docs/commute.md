# 통근시간을 어떻게 계산하는가

← [README](../README.md)

이 서비스의 설계에서 가장 중요한 결정입니다. 여기서 나머지가 거의 다 따라옵니다.

---

## 외부 길찾기 API를 쓰지 않습니다

목적지 하나당 **547개 동의 통근시간**이 필요합니다. 길찾기 API를 쓰면 요청당
547콜이라, ODsay 무료 티어(1,000콜/일)로는 **하루 1명**밖에 못 씁니다.

대신 **지하철 그래프를 직접 만들어 브라우저에서 Dijkstra를 돌립니다.**

```
목적지 좌표
  → 반경 1.5km 내 지하철역 + 도보시간
  → 다중 출발점 Dijkstra (758노드 / 1,822엣지, 1ms 미만)
  → 역별 최단 도달시간
  → 각 행정동: min(동중심→인근역 도보 + 그 역 도달시간)
```

목적지 쪽에서 한 번만 돌리면 모든 역까지의 최단시간이 나오므로, 동이 547개든
4,000개든 계산량이 늘지 않습니다.

외부 API 호출이 **0회**라 사용량 제한도 요금도 없고, 슬라이더를 드래그해도
네트워크 왕복 없이 즉시 반응합니다. 선택한 동의 경로는 Dijkstra의 `prev` 배열로
그때 되짚습니다 — 547개를 미리 만들면 대부분 버려집니다.

## 노드는 "역"이 아니라 "(역, 노선)" 쌍입니다

강남역은 2호선 노드와 신분당선 노드로 나뉘고 그 사이를 환승 엣지가 잇습니다.
이렇게 해야 환승 비용이 경로 탐색에 자연스럽게 반영됩니다.

623개 역이 **758개 노드**가 되고, 그중 114개가 환승역입니다.

---

## 역간 소요시간 = 정차 페널티 + 거리 / 순항속도

노선별 "표정속도"를 하나씩 찍는 방식은 역간거리가 짧은 노선(6호선)과 긴 노선
(GTX)을 동시에 맞출 수 없습니다. 표정속도 자체가 역간거리에 종속된 값이기
때문입니다. 물리적으로 분해하면 상수 두 개로 경전철부터 GTX까지 설명됩니다.

검증 (`src/lib/commute.test.ts`):

| 구간 | 모델 | 실제 |
|---|---|---|
| 2호선 순환 일주 (43역 48.8km) | 87.5분 | 87분 |
| 1호선 서울역–인천 (27역) | 62분 | 약 60분 |
| 6호선 응암–봉화산 (38역) | 70분 | 약 75분 |
| 신분당 강남–정자 (6역) | 18분 | 약 16분 |
| 우이신설 전 구간 (13역) | 25분 | 약 24분 |

`src/lib/constants.ts` 의 통근 모델 상수를 바꾸면 **반드시 `npm test`** 를
돌리세요. 2호선 순환 일주 87분을 앵커로 캘리브레이션되어 있습니다.

## 표시되는 구간 시간의 합은 헤드라인과 일치합니다

총 통근시간에만 들어 있던 최초 승차 대기(3분)를 구간으로 드러낸 이유입니다.
드러내기 전에는 구간 합이 33분인데 헤드라인이 36분이라 검산이 안 됐습니다.

구간별로 반올림하므로 1분 차이는 남을 수 있고, 반올림해서 0분이 되는 구간은
표시에서 지웁니다.

---

## 도보 보정 계수는 실측값입니다

`WALK_DETOUR_FACTOR`(직선거리 → 실제 도보거리)는 **1.4**이며 감으로 찍은 값이
아닙니다. `npm run data:calibrate-walk` (OSM 보행망, 키 불필요) 또는
`-- --source=seoul` (서울시 공식 보행망, `SEOUL_OPEN_DATA_KEY` 필요)로
재현합니다. 두 소스 교차검증 결과가 1.397 대 1.418로 1.5%p 차이라 1.4를
유지했습니다.

이 값은 `scripts/lib/geo.mjs` 에도 복제돼 있습니다(.mjs 가 TS 를 못 읽어서).
한쪽만 바꾸면 화면 통근시간과 "최근접역 도보" 지표가 서로 다른 계수로 계산되는데
둘 다 그럴듯해서 눈으로는 못 잡습니다 — `commute.test.ts` 가 이걸 막습니다.

역을 **고를 때**만 도보에 가중치(`WALK_SELECTION_WEIGHT`)를 걸어, 총 시간이
비슷하면 도보가 적은 역을 고릅니다. 화면에 나오는 총 소요시간과 구간 텍스트는
항상 가중치 없는 실측값입니다.

## 한계

- **역간 소요시간은 전 구간 추정치**이며 실측이 아닙니다 (위 검증표 참고)
- **환승 도보시간이 상수 2분**입니다 (실제 1~10분). OSM에 정보가 없습니다
- **급행 미반영** — 9호선 급행, 1호선 급행 등은 제외하고 완행 기준입니다
- **노선도·경로선은 역 좌표를 직선으로 이은 것**이지 실제 선로 모양이 아닙니다.
  통근 경로를 점선으로 그리는 것도 그래서입니다
- **버스는 통근 계산에 넣지 않습니다** — 배차·교통상황 데이터가 없어 검증이
  불가능합니다. 버스는 생활편의 축의 정류장 밀도로만 반영됩니다

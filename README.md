# I Don't Know Seoul

**https://i-dont-know-seoul.cioud.workers.dev**

갓 상경해 자취방을 구할 때, 회사나 학교를 검색하면 **통근 가능한 서울 동네들이
평판 등급으로 칠해진 지도**를 보여줍니다.

- 서울과 신분당선 축(수원·성남·용인) **547개 행정동**을 Best / Normal / Bad 로 등급화
- 목적지 기준 **통근시간**을 지하철 그래프로 직접 계산 (외부 길찾기 API 호출 0회)
- **치안 / 가격 / 생활편의** 가중치를 직접 조절 → 즉시 재계산
- 등급이 왜 그렇게 나왔는지 **계산 과정을 전부 공개**
- **목적지 여러 개** — "우리 둘 다 40분 이내인 동네" (최대 3곳)
- **예산 필터**로 월세 상한을 잘라내고, 지도를 등급/통근시간으로 전환
- **지하철 노선도** 오버레이 (623개 역, 21개 노선) — 노선별 on/off
- 찾은 결과를 **링크로 공유**, 다크/라이트 테마

---

## 이 지도를 어떻게 읽는가

**등급은 절대 평가가 아니라 서울 안에서의 상대 평가입니다.** 상위 30%가 Best,
하위 30%가 Bad입니다. "Bad"는 살 수 없는 동네라는 뜻이 아니라, 같은 조건에서
비교했을 때 서울 하위권이라는 뜻입니다.

세 축으로 봅니다.

| 축 | 무엇을 보는가 | 기본 가중치 |
|---|---|---|
| **치안** | 유흥업소 밀도, 5대범죄(자치구), 교통사고 다발지역 | 40% |
| **가격** | 환산월세 중앙값 (단독·다가구·오피스텔·소형아파트) | 35% |
| **생활편의** | 편의점·마트, 음식점, 병원·약국 밀도, 교통 접근성(역 도보 + 버스) | 25% |

가중치 슬라이더가 있는 이유는 **정답이 사람마다 다르기 때문**입니다. 월세가
제일 중요한 사람과 조용한 동네가 제일 중요한 사람에게 같은 순위를 강요할 근거가
없습니다. 슬라이더를 움직이면 등급, 추천 순서, 요약 문장이 전부 즉시 바뀝니다.

동을 클릭하면 **왜 그 등급인지**가 나옵니다. (목적지를 강남역으로 뒀을 때)

```
동작구 노량진1동                            ● Best
수도권 547개 동 중 100위 · 상위 18%

"월세가 60만원으로 싸고 범죄는 적지만, 교통사고 다발지점이 많습니다."

31분                                        환승 1회
  8분  노들역까지 도보
  3분  승차 대기
 13분  9호선 7정거장 · 노들 → 신논현
  5분  신논현역 환승 · 9호선 → 신분당선
  1분  신분당선 1정거장 · 신논현 → 강남

치안    ▓▓▓░░ 69                          ▸ 계산 과정
가격    ▓▓▓▓░ 77                          ▸ 계산 과정
생활편의 ▓▓░░░ 45                          ▸ 계산 과정
```

숫자가 어떻게 나오는지는 → **[등급 계산 방식](./docs/scoring.md)**

지도 좌상단의 **지하철 노선도** 토글로 노선을 켜고 끌 수 있습니다. 노선 색은
실제 노선색 그대로이고, 환승역은 다른 점으로 구분되며, 확대하면 역 이름이 나옵니다.
"노선" 범례에서 개별 노선을 끌 수도 있고, 노선에 커서를 올리면 몇 호선인지 뜹니다.
지도의 역을 클릭하면 바로 목적지가 됩니다.

### 목적지를 여러 개 둘 수 있습니다

커플이 각자 다른 회사에 다니거나 회사 + 학원처럼, **"둘 다 40분 이내인 동네"**를
찾는 건 흔한 니즈입니다. 목적지를 최대 3곳까지 더하면 **모두 만족하는 지역**만
남습니다.

```
강남역만          → 통근권 146개 동
강남역 + 여의도역 → 통근권  76개 동
```

판정은 가장 오래 걸리는 쪽 기준입니다. 평균이나 합을 쓰면 "한 명은 20분, 다른
한 명은 90분"인 동네가 통과해버립니다.

### 지도 색은 두 가지로 볼 수 있습니다

**등급**(초록–노랑–빨강)과 **통근시간**(파랑 농담) 중에 고릅니다. 통근시간 모드는
20·30·40·60분 밴드로 칠해 등시선처럼 보입니다. 두 모드의 색 계열을 다르게 둔
이유는, 같은 계열이면 "빨간 동네가 나쁜 건지 먼 건지" 구분이 안 되기 때문입니다.

### 찾은 결과는 링크가 됩니다

목적지·통근한계·가중치·예산·지도 모드가 전부 주소에 담깁니다. 링크를 받은 사람은
같은 화면을 그대로 봅니다. 서버에 아무것도 저장하지 않습니다.

## 빠른 시작

```bash
npm install
npm run cf:dev   # → http://localhost:8787
npm test         # 회귀 테스트 86개
```

데이터 번들이 저장소에 들어 있어 **API 키 없이도 바로 돌아갑니다.** 데이터를
직접 다시 만들려면 → **[직접 돌리고 배포하기](./docs/development.md)**

## 알려진 한계

| 한계 | 성격 |
|---|---|
| CCTV 밀도 미반영 | 원 데이터셋이 폐기됐고 대안이 없습니다 |
| 5대범죄가 자치구 단위 | 공개 데이터의 해상도 한계. 같은 구의 동은 값이 같습니다 |
| 월세가 법정동 단위 | 같은 법정동의 행정동은 값이 같습니다 |
| 버스는 정류장 밀도만 | "정류장이 많다"이지 "노선이 다양하다"가 아닙니다 |
| 통근시간은 추정치 | 실측이 아니며, 급행과 실제 환승 도보시간이 빠져 있습니다 |
| 대형마트·백화점 미반영 | 소상공인 데이터가 대기업 점포를 제외합니다 |

각 항목의 근거와 실측치는 [데이터](./docs/data.md#알려진-한계-정리) ·
[통근시간 계산](./docs/commute.md#한계) 에 있습니다.

## 등급 표기에 대해

특정 동네를 공개적으로 "Bad" 로 규정하는 일입니다. 다음을 항상 지킵니다.

1. 등급 옆에 **근거가 되는 실제 수치를 함께 노출**합니다 (유흥업소 185.29개/km² 등)
2. "공공·공개 데이터로 계산한 서울 내 **상대 평가**이며 특정 지역에 대한
   가치판단이 아닙니다" 면책 문구를 상시 표시합니다
3. 데이터 기준일과 출처를 명시합니다
